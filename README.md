# Verizon NLE — Сверхпроизводительный видеоредактор (Wayland Native)

Современная альтернатива DaVinci Resolve для Linux/Wayland на базе **Rust**, **Vulkan (wgpu)** и **egui**.

## Ключевые возможности MVP

* **Аутентичный дизайн DaVinci Resolve (Blackmagic Look & Feel)**:
  * Профессиональная темная палитра (`#151618`, `#1c1d20`, `#222428`).
  * Фирменный оранжевый акцент Blackmagic (`#e87c24`).
  * Цветовое кодирование дорожек: сине-стальные видео-клипы (V1, V2) и хвойно-зеленые аудио-клипы (A1, A2).
  * Нижняя панель страниц DaVinci: `[ Media ] [ Cut ] ★ [ Edit ] ★ [ Color ] [ Deliver ]`.
* **Док-система страницы Edit (Edit Page)**:
  * **Media Pool**: папки (Bins), список клипов с метаданными (4K UHD, ProRes, HEVC, PCM audio, fps, таймкод).
  * **Dual Viewers**: Source Viewer (исходник) и Timeline Program Viewer (композиция).
  * **Аудио VU-метры**: стерео-индикаторы с dB-шкалой (-inf .. +3dB) в реальном времени.
  * **Инспектор (Inspector)**: Transform (Zoom X/Y со связыванием, Position X/Y, Rotation Angle, Opacity) и Audio (Volume dB, Pan).
* **Интерактивный таймлайн**:
  * Фирменный оранжевый плейхед с треугольным бегунком и направляющей.
  * Плавный скраббинг мышью на 144+ FPS.
  * Инструменты монтажа:
    * `A` — Стрелка выделения и перемещения клипов.
    * `B` — Лезвие (Blade) с интерактивной красной линией резки.
    * `Ctrl + B` — Быстрый разрез всех клипов под плейхедом.
    * `N` — Включение/выключение магнитного прилипания (Snapping).
    * `I` / `O` — Установка точек входа (In) и выхода (Out).
    * `Space` — Воспроизведение / Пауза.
    * `J` / `K` / `L` — Реверс 2x / Пауза / Вперед 2x (Shuttle).
    * `Delete` / `Backspace` — Удаление выбранного клипа.
    * `Ctrl + Z` — Недеструктивная отмена действия (Undo).
  * Отрисовка звуковых волноформ (waveforms) прямо на теле аудиоклипов.

---

## Запуск

В NixOS или любой системе с установленным Nix:

```bash
./run.sh
```

Либо вручную через Cargo:

```bash
nix-shell shell.nix --run "cargo run"
```
